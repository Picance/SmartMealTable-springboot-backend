## 회원

추천 시스템의 기준이 될 수 있는 사용자 정보를 입력받습니다.

- 거주지, 학교, 직장, …
    - 사용자가 주로 식사하는 장소(위치)를 입력받습니다.
    - 사용자가 식사할 장소를 빠르게 선택할 수 있도록 거주지, 학교 / 직장 정보를 미리 저장합니다.
- 음식 취향
    - 선호하는 음식
    - 불호 (추천 리스트에서 제외)
    - 음식 취향에 맞는 음식 선호도에 가중치(순위별)를 부여합니다. 이후 추천 및 정렬 / 핕러링 기준으로 사용됩니다.

## 예산

사용자로부터 초기 예산을 입력받아, 지출 후 남은 예산을 바탕으로 가게를 추천합니다.

- 월별 예산
    - 사용자 초기 예산 입력
    - 사용자가 지출을 하게 되면 사용한 금액만큼 월별 예산에서 차감을 하여 데이터베이스에 업데이트합니다.
- 일별 예산
    - 업데이트 된 예산을 통해 가게를 추천할 수 있도록 합니다.
    - 사용자가 지출을 하게 되면 사용한 금액만큼 일별 예산에서 차감을 하여 데이터베이스에 업데이트합니다.

## 음식점 및 추천

사용자에게 남은 예산 및 선호도(음식 취향)를 기반으로 가게를 추천합니다.

- 음식점
- 학식
- 편의점(추후 추가)

### 음식점 정보 처리

- 구현: 카카오 Open API 이용
    - https://developers.kakao.com/docs/latest/ko/local/dev-guide
    - 주소를 좌표로 변환한 뒤, 해당 좌표 기반 음식점 정보를 가져옵니다.
    - 음식점 정보를 토대로 음식 및 메뉴 정보를 파싱합니다.
- 테이블
    - 가게 운영 시간
    - 음식
        - 음식 종류
        - 음식 이름
        - 가격
    - 주소 정보(좌표)
    - 음식점 분류
        - 학교 식당
        - 일반 음식점
        - 편의점

### 학식 정보 처리

- github에 오픈소스로 풀려있는 학교별 학식 정보 파싱 코드를 이용하여 데이터베이스에 저장
- 주기적인 batch 작업을 통해 데이터베이스 업데이트
    - 1일 단위(자정)
- 몇 개 학교를 우선으로 작업 진행

### 편의점 정보 처리

https://github.com/HongikUniv-CAPSTONE-DESIGN-2023-YDY-1/CAPSTONE_DESIGN_BackEnd_DATA_SCRAPING

- Spring Boot 기반 오픈소스로 공개되어있는 편의점 상품 정보 모듈을 이용
- 주기적인 batch 작업을 통해 데이터베이스 업데이트
    - 1일 단위(자정)
- 기본적인 기능이 개발된 후에 시간적 여유가 된다면 구현할 예정

### 추천 알고리즘

코사인 유사도 알고리즘을 통해 추천 알고리즘을 구현합니다.

- **사용자 선호도 벡터 생성**
    - 선호/비선호 음식 종류, 예산, 위치 정보 등 사용자의 여러 속성들을 하나의 벡터로 변환합니다.
        - ex) 한식(5점), 양식(2점), 중식(0점), 일식(4점), 분식(3점)
        - 
- **음식점 벡터 생성**
    - 각 가게가 제공하는 음식 종류, 해당 음식 평균 가격대, 위치 등을 마찬가지로 벡터로 표현합니다.
- **코사인 유사도 계산**
    - 사용자 벡터와 가게 벡터 간 코사인 유사도를 계산하여, 유사도가 높은 순서대로 가게를 추천합니다.
    - 코사인 유사도가 1(또는 100%)에 가까울수록 사용자의 선호와 가게 특성이 유사하다고 볼 수 있습니다.

### 정렬

- 높은 가격 순
- 낮은 가격 순
- 취향 순
- 가까운 순 정렬

### 필터링

- 가격대별 필터링
- 학식/가게/편의점 필터링

### 추천 시스템을 통해 해결할 수 있는 문제

- 음식 취향 + 위치 기반으로 **맞춤 추천**을 제공함으로써, 사용자는 고민 없이 빠르게 식사를 결정하고 시간을 절약한다.
- 사용자의 **남은 예산**과 **일별 식비 한도**를 기반으로, 예산 내에서 갈 수 있는 장소만 추천함으로써 합리적인 소비를 유도한다.
- 지출 내역 분석 + 남은 예산을 기반으로 오늘 먹을 수 있는 범위의 장소만 추천해서 **과소비를 방지한다.**
- 학식, 편의점 음식, 가게 음식 등 **다양한 식사 대안**을 함께 추천해 **식사 루틴을 다양화한다.**

## 지출 내역

계좌 내의 지출 내역 중 음식점과 관련된 데이터를 조회하여 사용자에게 식비 지출 내역을 보여줍니다.

### 지출 내역 조회

금융 결제원 오픈 Api를 활용합니다.

- https://developers.kftc.or.kr/dev/openapi/open-banking/transaction
- OAuth 2.0 기반입니다.
- 실시간 이벤트 스트리밍 기반이 아니라, 사용자가 지출 후 새로 고침 시 업데이트하도록 구현할 예정입니다.

### 보여줄 데이터

- chart.js를 이용한 지출 내역 그래프화
    - 설정한 한도를 기준으로 식비 지출이 목표 예산을 넘었는지 유뮤를 그래프로 시각화합니다.
- 지출한 식당과 금액을 리스트로 출력합니다.
    - 일자 별로 지출 내역을 그룹화하여 목표 예산과의 차액을 보여줍니다.

### 지출 내역 조회 시스템을 통해 해결할 수 있는 문제

- 사용자에게 식비를 절약할 수 있는 동기를 부여
- 사용자 스스로 합리적인 식비 지출 계획을 세울 수 있도록 도움

### 즐겨찾기 및 자주 방문한 음식점

사용자가 즐겨찾기로 추가한 가게 및 자주 방문한 음식점 정보를 출력합니다.

- 자주 방문한 음식점 정보
    - 지출 내역에서 도출한 정보를 바탕으로 구성합니다.
- 즐겨찾기
    - 가게 정보 페이지에서 즐겨찾는 가게 목록에 추가할 수 있음.
